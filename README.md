# 자연속 캠핑 배치도 (GitHub Pages)

- **화면**: `index.html` → GitHub Pages에 올립니다. 주소는 `https://아이디.github.io/저장소이름/` 형태입니다.
- **예약 저장**: `google-apps-script/Code.gs` → Google 스프레드시트에 붙은 Apps Script입니다. GitHub Pages는 데이터를 저장할 수 없어서 저장은 Google이 맡습니다.

공개 저장소라 이 저장소의 파일은 누구나 볼 수 있습니다. 그래서 직원 비밀번호는 코드에 적지 않고, Apps Script의 **스크립트 속성**에만 저장합니다. 스크립트 속성은 내 Google 계정에서만 볼 수 있습니다.

---

## 1단계: 예약 저장 서버 만들기 (Google)

1. https://sheets.new 에서 새 스프레드시트를 만듭니다. 제목은 예를 들어 `자연속 캠핑 예약`으로 합니다.
2. **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 내용을 모두 지우고 `google-apps-script/Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 **프로젝트 설정(톱니바퀴)** → 맨 아래 **스크립트 속성 → 스크립트 속성 추가**를 누릅니다.
   - 속성: `STAFF_PIN`
   - 값: 직원 비밀번호(6자리 이상, 영문·숫자를 섞으면 더 안전합니다)
   - **스크립트 속성 저장**을 누릅니다. 비밀번호를 바꿀 때도 여기서 값만 바꾸면 되고, 다시 배포할 필요가 없습니다.
5. **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한을 허용합니다. "확인하지 않은 앱" 경고가 나오면 **고급 → 이동**을 누릅니다.
7. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
   - 이 주소를 브라우저로 열었을 때 "예약 서버가 작동 중입니다"가 보이면 정상입니다.

## 2단계: 화면에 서버 주소 넣기

`index.html`을 메모장으로 열고, `<script>` 바로 아래 줄을 찾습니다.

```js
const API_URL = "여기에_웹앱_URL을_붙여넣으세요";
```

따옴표 안을 1단계에서 복사한 주소로 바꾸고 저장합니다.

## 3단계: GitHub Pages 켜기

파일은 이미 이 저장소(`pibic98-won/campmap`)에 올라가 있습니다. `.nojekyll` 파일은 Jekyll 변환 없이 그대로 배포하라는 표시입니다.

1. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: `index.html`이 있는 브랜치, 폴더 **/(root)** → **Save**
2. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://pibic98-won.github.io/campmap/`

## 사용하기

- **손님**: 주소를 열면 배치도, 사이트 크기, 날짜별 예약 현황(빨간색)을 볼 수 있습니다. 메모는 보이지 않습니다.
- **직원**: **직원 로그인**에 비밀번호를 넣으면 예약 체크와 메모 입력을 할 수 있습니다.
- 예약 내역은 스프레드시트의 **예약** 시트에도 쌓입니다. 화면은 30초마다 새로 고쳐집니다.

## 고칠 때

- **화면을 고칠 때**: GitHub 저장소에서 `index.html`을 수정(연필 아이콘)하거나 다시 업로드하면 1~2분 뒤 반영됩니다.
- **서버(Code.gs)를 고칠 때**: Apps Script에서 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 누릅니다. 이렇게 해야 주소가 그대로 유지됩니다.
  - **새 배포**를 누르면 주소가 바뀌니, 그 경우 `index.html`의 `API_URL`도 같이 바꿔야 합니다.

## 문제 해결

- **"예약 현황을 불러오지 못했습니다"가 뜰 때**
  - `API_URL`이 `/exec`로 끝나는 주소인지 확인합니다.
  - 웹 앱 액세스 권한이 "모든 사용자"인지 확인합니다.
- **나만의 도메인(예: camp.example.com)을 쓰고 싶을 때**: Settings → Pages → Custom domain에서 연결할 수 있습니다.
